# 100 Days of Code: The Complete Python Pro Bootcamp

This repository serves as the official project archive for my 100-day journey through a comprehensive Python curriculum. The program is designed to build mastery from fundamental principles to advanced, portfolio-ready applications.

Each day's work, including all code, exercises, and project files, is organized into its respective folder (e.g., `Day-001`, `Day-002`, etc.).

---

## Curriculum Overview

This curriculum is structured to cover a wide array of topics, grouped into several key domains:

### 1. Python Fundamentals (Days 1-14)
The foundation of the course, covering essential syntax, data types, control flow, functions, and debugging.
* **Key Projects:** Hangman, Caesar Cipher, Secret Auction, Number Guessing Game.

### 2. Intermediate Python & OOP (Days 15-23)
Focuses on more complex concepts, including Object-Oriented Programming (OOP), local development, and building projects with graphical interfaces.
* **Key Projects:** Coffee Machine, Quiz Project, Snake Game, Pong, Turtle Crossing.

### 3. GUI & Application Development (Days 24-32)
Deep dive into desktop application development using Tkinter, file handling, JSON, and error management.
* **Key Projects:** NATO Alphabet, Pomodoro GUI, Password Manager, Flash Card App.

### 4. APIs & Automation (Days 33-40)
Introduces interaction with external services, sending emails, managing environment variables, and building API-driven applications.
* **Key Projects:** ISS Overhead Notifier, GUI Quiz App, Stock Trading News Alert, Habit Tracker, Flight Deal Finder.

### 5. Web Foundations (Days 41-44 & 58)
Covers the core technologies of the modern web: HTML, CSS, and the Bootstrap framework.

### 6. Web Scraping & Automation (Days 45-53)
Focuses on data extraction and browser automation using Beautiful Soup and Selenium.
* **Key Projects:** Spotify Playlist Creator, Amazon Price Tracker, Tinder Swiping Bot, Data Entry Automation.

### 7. Full-Stack Web Development (Days 54-71)
Builds complete, database-driven web applications using Flask, Jinja, WTForms, SQLAlchemy, and RESTful APIs.
* **Key Projects:** Higher Lower Game, Blog Capstone, Coffee & Wifi Project, Top 10 Movies Website.

### 8. Data Science & Visualization (Days 72-81)
Covers the full data science stack, including analysis with Pandas, computation with NumPy, and visualization with Matplotlib, Plotly, and Seaborn.
* **Key Projects:** LEGO Dataset Analysis, Google Trends Analysis, Nobel Prize Winners, House Price Prediction.

### 9. Professional Portfolio (Days 82-100)
The final stretch, dedicated to building a diverse portfolio of 19 unique, professional-grade projects across all learned domains.

---

## Technology Stack

This course covers a wide range of professional tools and libraries, including:

* **Core:** Python 3
* **Data Science:** Pandas, NumPy, Matplotlib, Seaborn, Plotly
* **Web Development:** Flask, Jinja, WTForms, SQLAlchemy
* **Web Technologies:** HTML5, CSS3, Bootstrap
* **Automation:** Selenium, Beautiful Soup
* **GUI:** Tkinter, Turtle
* **APIs:** REST, JSON, `smtplib`
* **Tools:** Git, GitHub, Virtual Environments
